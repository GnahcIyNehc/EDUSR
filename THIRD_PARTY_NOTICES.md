# Third-party notices and licensing

The streaming model, data pipeline, and generation components build on StreamingThinker and Qwen3. `ST_RL/HRPO` provides the HRPO implementation required by EDU-HRPO. `Streaming_EDU` and `EDU_codex` contain the segmenter inference and training components.

Existing copyright and license notices in source files are retained. Third-party notices identify upstream contributors, not the anonymous submission authors. Model checkpoints and datasets are distributed separately under their respective terms.

This release does not add a repository-wide license. No single license covering the assembled code was identified in the selected source directories. Rights holders should specify the license for their original contributions and ensure that all upstream distribution requirements are satisfied. Public availability alone does not grant a blanket reuse license.

The method builds on StreamingThinker, AdaSR/HRPO, and Qwen3. File provenance and changes are recorded in `SOURCE_MANIFEST.json` using relative paths only.
